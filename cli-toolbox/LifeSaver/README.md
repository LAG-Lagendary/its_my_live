🚀 Life-Saver: Дебиан сдох? Не паникуй!

Скрипт для меня когда Дебиан решил уйти в отставку, а у меня дедлайны горят... Этот скрипт — мой личный реаниматор. Накатит всё нужное за пару минут, пока я завариваю дошик.

🛠 Что он сейчас будем спасать:

    Безопасность: Firewall (UFW), AmnesiaWG.
    Сеть & Интернет: Ядро X-ray, Google Chrome, Rclone.
    Работа: LibreOffice, OpenOffice (если любишь ретро), GIMP (дизайним мемы), REAPER (пишем хиты).
    Комфорт: Kate, Dolphin.
    Удаленка: AnyDesk (чтобы помогать тем, у кого Дебиан пока еще живее моего).

⚡️ Как воскресить систему (Quick Start)

Забудь про ручное скачивание архивов и переходы по ссылкам. Открывай терминал и делай магию:
Bash

bash -c "$(curl -fsSL https://raw.githubusercontent.com/LAG-Lagendary/its_my_live/cli-toolbox/LifeSaver/install.sh)"

    Запустил? Молодец.
    Выбрал: Цифрами через пробел отметь то, что нужно вернуть в строй (например: 1 3 5 8).
    Enter: Иди кури/пей кофе. Скрипт сделает всё за тебя.

📋 Инструкция для «тяжелых случаев»

Если Дебиан не просто «приболел», а приказал долго жить:

    Ставь чистый Debian (минималку).
    Обновись: sudo apt update && sudo apt upgrade -y.
    Запускай этот репозиторий.
    Наслаждайся рабочим окружением, которое круче, чем было до «смерти».

    ⚠️ Дисклеймер: Скрипт делает именно то, что написано. Если ты накосячил с конфигами — это на твоей совести. Мы лишь предоставляем молоток, а забиваешь гвозди ты сам.
