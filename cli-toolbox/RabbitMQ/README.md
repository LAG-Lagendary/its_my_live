# Its My Live Agent

Фоновый агент (воркер) на Python для безопасного удаленного мониторинга состояния сервера через брокер сообщений RabbitMQ.

## 📝 Описание проекта

**Its My Live Agent** — это легковесный системный сервис, который слушает определенную очередь в RabbitMQ и выполняет строго ограниченный набор системных команд для мониторинга сервера.

Главная особенность архитектуры — **абсолютная безопасность**. Агент защищен от инъекций произвольного кода, так как использует жестко заданный «белый список» (White-list) команд. Через него невозможно выполнить сторонний вредоносный код или нарушить работу ОС.

### Как это работает:
1. Сторонняя система (или администратор) отправляет текстовую задачу (триггер) в очередь RabbitMQ.
2. Агент забирает задачу, проверяет её по белому списку.
3. В случае успеха — выполняет команду на сервере, логирует результат и подтверждает выполнение задачи (ACK).
4. В случае неизвестной команды — блокирует её выполнение и пишет предупреждение в лог.

## 🛠 Архитектурная схема

```text
[ RabbitMQ Producer ] 
         │
         ▼ (Сообщение: "disk", "memory" или "status")
┌────────────────────────────────────────┐
│            RabbitMQ Queue              │
└────────────────────────────────────────┘
         │
         ▼ (Prefetch: 1)
┌────────────────────────────────────────┐
│         its_my_live_agent              │
│  ├─ Проверка по белому списку          │
│  └─ Безопасный запуск (subprocess)     │
└────────────────────────────────────────┘
         │
         ▼
┌────────────────────────────────────────┐
│          Системные логи                │
│  ├─ Консоль (stdout)                   │
│  └─ /var/log/its_my_live/agent.log     │
└────────────────────────────────────────┘
