CLI Toolbox Installer

Удобный инструмент для быстрой настройки рабочего окружения. Скрипт автоматически сканирует директорию с инструментами, предлагает выбрать нужные и запускает их установку.
🛠 Как это работает

    Скрипт ищет в папке cli-toolbox подпапки, внутри которых есть файл install.sh.
    Выводит интерактивный список всех найденных инструментов.
    Вы выбираете нужные компоненты, вводя их порядковые номера.
    Скрипт последовательно выполняет команды установки для каждого выбранного инструмента.

🚀 Использование

    Поместите скрипты установки (например, install.sh) в соответствующие папки внутри cli-toolbox/.
    Запустите основной файл:
    
    Bash
    curl -s https://raw.githubusercontent.com/LAG-Lagendary/its_my_live/main/its_my_live.py | python3

    Введите номера нужных инструментов через пробел и нажмите Enter.

⚙️ Требования

    ОС на базе Unix (Linux/macOS).
    Установленный Python 3.
    Наличие прав на выполнение команд (для скриптов установки).

Быстро, просто и без лишней суеты.
